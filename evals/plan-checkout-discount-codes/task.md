# Plan discount codes for checkout

Perihelion wants customers to enter a discount code at checkout (for example `PERSEIDS10` for 10% off, or a fixed $25 off orders over $300). Codes have an expiry date and a usage limit.

Write an implementation plan for adding discount codes to this checkout service. Save it as `docs/plans/discount-codes.md`. Do not implement the feature; only write the plan.

The plan should be detailed enough for another engineer to implement it without asking you questions.
